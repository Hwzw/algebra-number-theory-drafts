# Maximal-elasticity length sets for families of two-groups of exponent eight

**Henry Zweiman** · September 9, 2026

[Full paper in Markdown](manuscript.md) · [PDF](manuscript.pdf) · [LaTeX source](manuscript.tex)

For a noncyclic group `G = C2^a + C4^b + C8^c`, the paper proves that every longest atom has signed-support minimum distance dividing three. This distance is one whenever `a+c` is not `1 mod 3`, or whenever `c=1`. The latter condition allows arbitrary numbers of order-two and order-four factors. For these families, maximal-elasticity length sets in transfer Krull monoids have an interval as their central part, with uniformly bounded exceptional ends.

The six-page manuscript gives universal hand proofs, including the signed-support classification and the group-algebra argument that excludes residual order-two terms. The general exponent-eight case remains unresolved.
