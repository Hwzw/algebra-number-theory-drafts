# Torsion transplantation and a uniform reverse Kohler-Jobin inequality for Robin problems

Henry Zweiman. September 15, 2026.

An eight-page research preprint proposing an affirmative answer to the planar reverse Robin Kohler-Jobin question of Buttazzo, Cito and Solombrino. Balls uniquely maximize the first Robin eigenvalue times a sufficiently large power of torsional rigidity among all bounded planar Lipschitz sets of fixed area. The exponent is uniform in the positive Robin parameter and area. The same proof gives a nonlinear extension for 1<p<=n/(n-1), linear spectral-deficit control and equivalent product/torsion deficits.
